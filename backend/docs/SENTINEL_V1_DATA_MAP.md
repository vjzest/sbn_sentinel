# SENTINEL V1 DATA MAP
**Purpose:** Provides a minimal engineering reference for governed persistence models per SESR-012 Chapter 3.

## 1. Decision Evidence Record
- **Purpose:** Stores the governed Evidence snapshot that was used for a Decision.
- **Primary ID:** `evidence_id`
- **Important Relationships:** 
  - Belongs to `DecisionContextModel` (context_id)
- **Material State Fields:** `status` (SUFFICIENT / INSUFFICIENT / MISSING)
- **Material Version Fields:** `evidence_revision`
- **Material Timestamps:** `observation_time`
- **Protected Historical Fields:** `evidence_revision`, `observation_time`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr001.py`

## 2. Decision Context Model
- **Purpose:** Links an entity (patient) with their corresponding Evidence and Rule evaluations.
- **Primary ID:** `decision_context_id`
- **Important Relationships:** 
  - Has many `EvidenceModel`
  - Has many `RuleEvaluationModel`
- **Material State Fields:** `state` (CONSTRUCTED / DEGRADED)
- **Material Version Fields:** `version`
- **Material Timestamps:** `created_at`
- **Protected Historical Fields:** `version`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr002.py`

## 3. Rule Finding Model
- **Purpose:** The explicit evaluation of a single rule based on a Decision Context.
- **Primary ID:** `rule_finding_id`
- **Important Relationships:** 
  - Belongs to `DecisionContextModel`
- **Material State Fields:** `finding` (MATCH / NO_MATCH / UNKNOWN / ERROR)
- **Material Version Fields:** `rule_version`
- **Material Timestamps:** `evaluated_at`
- **Protected Historical Fields:** `rule_version`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr003.py`

## 4. Recommendation Model
- **Purpose:** The final logic-driven Recommendation generated by Sentinel.
- **Primary ID:** `recommendation_id`
- **Important Relationships:**
  - Has `DecisionContextModel`
- **Material State Fields:** `status` (ACTIVE / EXPIRED / RESOLVED)
- **Material Version Fields:** `mapping_version`, `policy_version`
- **Material Timestamps:** `generated_at`
- **Protected Historical Fields:** `mapping_version`, `policy_version`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr004.py`, `test_sesr010.py`

## 5. Human Decision Model
- **Purpose:** Stores the required explicit human authority granted to a Recommendation.
- **Primary ID:** `decision_id`
- **Important Relationships:**
  - Belongs to `RecommendationModel`
- **Material State Fields:** `decision_type` (APPROVED / REJECTED)
- **Material Version Fields:** None
- **Material Timestamps:** `decided_at`
- **Protected Historical Fields:** `decision_type`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr005.py`

## 6. Action Execution / Operational Event Model
- **Purpose:** Tracks the external action execution and outcome.
- **Primary ID:** `event_id`
- **Important Relationships:**
  - Belongs to `HumanDecisionModel` (if authority was required)
- **Material State Fields:** `status` (PENDING / COMPLETED / FAILED)
- **Material Version Fields:** None
- **Material Timestamps:** `executed_at`
- **Protected Historical Fields:** `status`
- **Relevant Migration:** None yet
- **Relevant Tests:** `test_sesr006.py`, `test_sesr008.py`
